# TodoList

Учебное приложение для создания, просмотра, переименования, отметки выполнения и удаления дел. Фронтенд и сервер собираются из одного репозитория и работают по одному HTTPS-адресу.

## Архитектура и API

- **Интерфейс.** React и TypeScript в `src/`. Vite собирает интерфейс в `dist/`, после чего Express раздаёт эти файлы и обслуживает API.
- **Сервер.** Express находится в `server/src/` и читает и записывает данные в PostgreSQL через Prisma. Маршруты API фильтруют дела по владельцу и при запросе списка требуют `runId`.
- **Доступ.** Публичный `GET /login/` возвращает логин Moodle обычным текстом. После ввода токена интерфейс отправляет `Authorization: Bearer <токен>` и получает логин и ФИО из `GET /api/author/`.
- **Изменения.** При создании дела клиент передаёт `title` и `runId`. При редактировании передаёт название, отметку выполнения или оба поля.

## Схема данных

Таблица `public.tasks` описана в [схеме Prisma](server/prisma/schema.prisma) и создаётся [SQL-миграцией](server/prisma/migrations/0_init/migration.sql). PostgreSQL назначает UUID. Сервер задаёт владельца из конфигурации, время создания и начальное значение `done=false`.

| Столбец PostgreSQL | Тип | Поле API |
| --- | --- | --- |
| `id` | `uuid`, первичный ключ, по умолчанию `gen_random_uuid()` | `id`, строка UUID |
| `owner_login` | `varchar` | `ownerLogin` |
| `title` | `varchar` | `title` |
| `done` | `boolean` | `done` |
| `run_id` | `varchar` | `runId` |
| `created_at` | `timestamptz(3)`, по умолчанию `CURRENT_TIMESTAMP` | `createdAt`, строка UTC ISO 8601 |

## Установка и запуск

1. Установите Node.js 24 и подготовьте отдельную базу PostgreSQL. Скопируйте `.env.example` в `.env` в корне репозитория.
2. Заполните параметры подключения. В `DIRECT_URL` задайте подключение с правами на применение миграций, в `DATABASE_URL` — подключение для работы приложения.
3. Задайте случайный `API_TOKEN`. Укажите `USER_LOGIN` и `USER_NAME` по профилю Moodle.
4. Установите зависимости, создайте таблицу миграцией, затем соберите и запустите приложение:

   ```sh
   npm ci
   npm run prisma:deploy
   npm run build
   npm start
   ```

Локальный адрес — `http://localhost:3000` или порт из `PORT`. В настройках Render укажите переменные среды, команду сборки `npm ci --include=dev && npm run build`, запуск `npm start` и путь проверки состояния `/health/`. Миграция применяется к целевой базе перед первым запуском.

## Проверка и доступ

- Дело, созданное через интерфейс, появилось в PostgreSQL. Переименование напрямую в БД отобразилось после повторной загрузки списка. Удаление через интерфейс убрало запись из таблицы.
- Для преподавателя создана отдельная роль `todo_reviewer` с правами `SELECT`, `INSERT`, `UPDATE` и `DELETE` на учебную таблицу. Вход под этой ролью проверен через `psql`.
- Параметры подключения к базе и токен API передаются преподавателю личным сообщением в Moodle.
