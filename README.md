# TodoList

## Приложение и архитектура

TodoList — учебное приложение для создания, просмотра, переименования, отметки выполнения и удаления дел. React-интерфейс находится в `src/`, сервер Express — в `server/src/`. После сборки Express раздаёт статические файлы Vite и обслуживает API на одном адресе. Браузер обращается к тому же домену, а сервер читает и записывает данные в PostgreSQL через Prisma. В проекте один набор команд установки, сборки и запуска.

## API и данные

Публичный `GET /login/` возвращает логин Moodle обычным текстом. В форме вводится токен, который клиент отправляет в заголовке `Authorization: Bearer <токен>`. Ответ `GET /api/author/` содержит логин и ФИО из серверной конфигурации. Список дел запрашивается по `runId` и ограничивается делами владельца. При создании клиент передаёт `title` и `runId`, при редактировании — `title` и/или `done`.

Таблица `public.tasks` описана в [схеме Prisma](server/prisma/schema.prisma) и создаётся [SQL-миграцией](server/prisma/migrations/0_init/migration.sql). База назначает UUID, сервер задаёт владельца, время создания и начальное значение `done=false`.

| Столбец PostgreSQL | Тип | Поле API |
| --- | --- | --- |
| `id` | `uuid`, первичный ключ, по умолчанию `gen_random_uuid()` | `id`, строка UUID |
| `owner_login` | `varchar` | `ownerLogin` |
| `title` | `varchar` | `title` |
| `done` | `boolean` | `done` |
| `run_id` | `varchar` | `runId` |
| `created_at` | `timestamptz(3)`, по умолчанию `CURRENT_TIMESTAMP` | `createdAt`, строка UTC ISO 8601 |

## Установка и запуск

Установите Node.js 24 и подготовьте отдельную PostgreSQL для проекта. Скопируйте `.env.example` в `.env`. В `DIRECT_URL` задайте подключение пользователя с правами на применение миграции, в `DATABASE_URL` — подключение для работы приложения. Задайте случайный `API_TOKEN` и заполните `USER_LOGIN` и `USER_NAME` по профилю Moodle. Миграция создаёт таблицу `public.tasks`. При первом запуске выполните команды из корня репозитория:

```sh
npm ci
npm run prisma:deploy
npm run build
npm start
```

Локальный адрес — `http://localhost:3000` или порт из `PORT`. На Render укажите сборку `npm ci --include=dev && npm run build`, запуск `npm start` и путь проверки состояния `/health/`. Передайте параметры среды в настройках сервиса. Примените миграцию к целевой базе перед первым запуском приложения.

## Проверка и доступ

Создание дела через приложение проверено по записи в PostgreSQL. Изменение названия напрямую в БД отобразилось после повторной загрузки списка, а удаление из приложения убрало запись из таблицы. Для проверки выделена роль `todo_reviewer` с правами `SELECT`, `INSERT`, `UPDATE` и `DELETE` на учебную таблицу. Подключение под этой ролью проверено через `psql`. Параметры подключения и токен передаются преподавателю лично в Moodle.
